## Moderation System

Enterprise-grade moderation with case tracking, consistent reasoning, and escalation logic. Virexa helps your staff act quickly while keeping a full audit trail in the database and dashboard.

**Key Features:**
- Unique case IDs for every action (warn, mute, kick, ban)  
- Enforced reasons for transparency and accountability  
- Automated escalation (for example, auto-ban after N warnings)  
- Support for mass actions during raids  
- Dashboard visibility into history and recent activity

[Learn More →](/en/core-features/moderation)

## Backup & Restore

Protect your server configuration against accidents, misconfiguration, or malicious actions. Virexa’s backup system focuses on **structure and configuration**, not message content, so it is fast and reliable.

**Key Features:**
- Backup of channels, categories, roles, and key server settings  
- Safe restore workflows for structural recovery  
- Ideal for major restructuring, migrations, and disaster recovery  
- Integrated into your existing moderation and logging flows

[Learn More →](/en/core-features/backup)

## Advanced Logging

Virexa listens to key Discord events and persists them for dashboards, audits, and troubleshooting.

**Key Features:**
- Logs for moderation events (warnings, kicks, bans, mutes)  
- Logs for channel and role changes  
- Message history snapshots for analytics and purge previews  
- WebSocket streaming of new logs to the dashboard  
- REST endpoint (`GET /api/logs`) for fetching recent activity

[Learn More →](/en/core-features/logging)

## Dashboard & API

Under the hood, the Virexa dashboard is just a client of the same FastAPI endpoints you can integrate with in your own tools and services.

**Key Features:**
- `GET /api/me` — Authenticated user profile for the current session  
- `GET /api/guilds` — List of guilds where the user is an admin  
- `GET /api/logs` — Recent log entries for tables and widgets  
- `WEBSOCKET /ws/logs` — Streaming log updates for real-time views  
- `POST /settings` — Server configuration (prefix, log channels, enabled events)

Use the dashboard for day-to-day management, and the documented endpoints when you need deeper automation or custom integrations.

## Quick Feature Comparison

| Feature | Purpose | Best For |
|--------|---------|----------|
| **Moderation** | Case-tracked moderation with escalation | Servers needing strict, auditable staff tools |
| **Backups** | Structural snapshots and restoration | Recovering from accidents or large changes |
| **Logging** | Persistent event history | Audits, incident reviews, and dashboards |
| **Roles** | Automated and persistent roles | Large communities and structured access control |
| **Purge** | Targeted message cleanup | Spam control and channel hygiene |
| **Boards & Counters** | Visibility into content and growth | Community engagement and reporting |
| **AFK & Reminders** | Status and follow-up management | Busy staff and active members |
| **Dashboard & API** | Centralized control surface | Teams needing UI plus programmable access |
